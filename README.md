# 方块斗兽场 · Unity 原型 0.13.0

四位指挥官招募方块生物、自由布阵，再让军团自动混战。支持本机对战三位电脑、局域网联机和自行配置 TCP 内网穿透。

[下载 v0.13.0 Windows 试玩包](https://github.com/hhhhhhhqcc/BlockArena/releases/download/v0.13.0/BlockArena-v0.13.0-Windows-x64.zip) · [Releases](https://github.com/hhhhhhhqcc/BlockArena/releases/tag/v0.13.0) · [生物图鉴](生物图鉴.md) · [Windows 试玩说明](Windows-试玩说明.md) · [验证记录](验证记录.md)

当前版本为 **v0.13.0 / 协议 v11，本机验收通过**；公开下载见上方 v0.13.0 Windows 试玩包。本版取消全屏战争黑雾，地图与普通敌军正常可见；用轻量淡化、图标和局部烟团表现原有隐蔽，攻击后的 2 秒暴露由服务器同步。修复雪天岸冰预览与中央向外展开，强化本方领地引导，并减少开战模型切换的集中开销。沿用四位指挥官语音、四倍战场随机部署、45 秒共享准备、120 秒战术编排与 120 秒自动战斗；默认 **R 指挥技、Q / E 向左 / 右转动视角 90°**，点击聊天即可输入，**Enter 发送**。最终验收结果见 [验证记录](验证记录.md)。

使用 Unity **2022.3.62f3c1**、Built-in 渲染管线。工程根目录可直接由 Unity 打开，当前 Windows 客户端输出目录为 `Builds/Windows-0.13.0`。构建文件与 Unity 缓存不提交到 Git，网页原型不属于本仓库。仍采用 v0.8 的构筑与经济，不包含遗物或单体装备系统。

## 开始试玩

Windows 玩家从上方 **v0.13.0 Release** 下载独立试玩包，完整解压后双击最外层的 **开始游戏.cmd**；包内只有中文入口、简短说明、`游戏文件` 和 `联机工具`，无需打开工程目录，也无需安装 Unity、.NET SDK 或 Node。向朋友分享时保留整个解压目录，不要只拷贝 exe；GitHub 自动生成的 Source code 是源码工程。源码工程本地构建后可使用根目录的 **开始游戏.cmd**，本地打包输出为 `Releases/v0.13.0/BlockArena-v0.13.0-Windows-x64.zip`。

- **单人试玩**：本机开服并添加三位电脑，过渡期间保留主菜单背景，直接进入对局；Esc 可取消进入。
- **创建房间**：先填写昵称与 TCP 端口，确认后开服进入大厅；房主开始时，空位可由电脑补齐。
- **加入房间**：先填写昵称、房主 IP / 穿透域名与 TCP 端口，确认后连接；连接中可取消并保留配置，失败后可修改重试。昵称、地址和端口保存在本机，最多四位玩家。
- **对局结束**：联机房主点击「返回大厅」返回原房间大厅，重新确认后开始新局。

主界面、创建房间、加入房间分别展示实时体素场景，大厅沿用对应背景。大厅四个席位集中展示玩家，可复制连接地址、选择指挥技；房主还能设置战场和开始对战。主菜单保留图鉴和设置入口。独立设置页使用第四套实时体素场景：铜制齿轮围绕悬浮水晶缓慢转动，红石回路与微光粒子构成工坊背景。

开发者可在 Unity Hub 添加源码工程根目录，使用上述 Unity 版本打开 `Assets/Scenes/Arena.unity` 后点击 Play；菜单 **方块斗兽场 → 打开试玩场景** 也可打开。菜单 **方块斗兽场 → 构建 Windows 试玩版** 输出至 `Builds/Windows-0.13.0`，构建后可使用工程根目录的启动脚本。本机安装路径匹配时，也可运行 **打开Unity工程.cmd**。运行 `Tools/Package-Release.ps1` 可将构建整理成上述玩家包，默认输出至 `Releases/v0.13.0`，同时生成 SHA256 校验文件；已存在的输出不会被覆盖。该脚本只整理本地文件，不会上传或发布。

设置分为「声音与辅助」「显示设置」和「按键设置」。显示页可选择**窗口 / 无边框全屏**及分辨率，点击「应用设置」后生效；以系统实际接受的模式和尺寸保存，下次启动使用。显示偏好保存在原生客户端本机，不随房间同步，服务器不保存；自动测试模式不读取或改写这些偏好。设置页也提供图鉴及当前房间入口，按 Esc 先关闭子页，再返回设置或游戏菜单。按键页可修改移动、指挥技、视角、商店、图鉴、复位和按住说话；重复占用会提示并保留旧键。Enter 和 Esc 保留，重绑时 Esc 只取消本次修改；按键仅保存在本机，可一键恢复默认。

## 招募、布阵与金币

每位指挥官 **20 点生命**，开局 **12 金币、两只基础生物**。开局及每轮战后，从三个不同候选中花金币招募一只，或跳过保留金币。招募卡片展示技能、精简效果和关键数值，可花 **2 金币「换一批」**更换候选，每轮仍最多买一只。超时由服务器购买可负担的生物，全部买不起则跳过。

每轮从招募出现起共用 **45 秒**准备时间；所有人完成招募后切换到布阵阶段，**保留剩余时间，不重新计时**。各人完成选择后即可布阵、购买技能或点击准备，不必等别人招募完。全部存活玩家均完成招募并准备好时，可提前开始地图揭晓。

招募页面可以**收起**，回场地查看生物、调整摆位或遣散，再点击「招募援军」恢复。收起不会购买或跳过，也不会暂停服务器倒计时。原「军团」窗口已移除：**单击生物打开固定属性框**，招募或准备时在己方生物属性框中遣散，返还实际购买价的一半、向下取整；免费初始生物返还 0，至少保留一只。待招募时可先遣散筹钱，再恢复招募页完成选择。

准备时只显示自己的独立领地。生物在地上活动，可拖到有效区域内任意位置，没有格子。拖动保留鼠标抓取偏移，服务器确认前保留落点以减轻延迟回弹。默认 WASD 按当前镜头的屏幕方向移动 Steve，四个席位和镜头转动时保持一致；或点击地面让 Steve 自动绕开地图障碍前往。

默认按 **M** 或点击商店购买永久技能，每批最多四项未掌握技能，准备期间不会定时自动换货；可花 **2 金币**主动刷新。共 13 项物种/类别技能，购买一次便作用于匹配的现有及未来生物，跨回合保留。技能详情列出全部适用物种、当前匹配数量；悬停时高亮场上匹配的己方生物。已购技能收藏保留。

有效击杀敌方原始军团生物，**每只 1 金币即时到账，每人每轮最多 5 金币**。战后补发 **基础 6 + 名次奖励 4/3/2/2**，常规整轮收入为 **6 + min(5，击杀数) + 名次奖励**，即 **8～15 金币**。召唤物和分裂体不给普通击杀金，毒、灼烧及己方召唤物击杀归主人。领先者按指挥官生命、上轮名次、军团战力选定并锁定，带琥珀皇冠；其他玩家每击杀其三只原始生物额外得一金币，每轮最多三金币。遣散、悬赏与地图目标奖励另计。

**旧中央守卫／随机金币事件及招募后的事件预告已移除。** 圣坛、矿脉、瞭望塔、信标和补给箱随对应地图自然生成，作为固定争夺目标；地图目标收入受每轮上限约束。

## 地图与天气

本轮流程为：**45 秒共享准备（招募、独立领地布阵、商店）→ 回到正常竞技场 → 抽取地图 → 底盘扩张 → 地形、草树与物体分层升起 → 抽取并揭晓天气 → 120 秒战术编排 → 最多 120 秒自动战斗 → 水晶结算**。揭晓总计约 **11 秒**，地图生成配合音效与轻微振动。房主可在大厅「战场设置」指定地图或天气，默认按地图池随机。

地图揭晓时，竞技场底盘从中央向外延伸，镜头随地图扩张逐渐后拉；Steve、军团和领地保持世界比例，迁移到服务器随机分配的部署方位，保留准备时的相对阵型。本方领地增加醒目边框和方向引导，便于在全景中定位。完整战场宽深各为旧版两倍、面积四倍，圆盘衔接竞技场边沿，保留合法坐标范围；地图地形、目标、碰撞、寻路和技能落点共用同一比例。

| 地图 | 地形与固定目标 | 默认天气池 |
| --- | --- | --- |
| 四庭高台 | 断崖圣坛与四座仪式长桥；侧庭补给形成外围争夺路线 | 晴朗、雷暴 |
| 腐沼矿场 | 连贯沼河、林地与废弃矿道；两岸矿脉和中央瞭望塔 | 降雨、浓雾、酷热 |
| 霜林遗迹 | 曲折冰河、石桥与双侧山脊；中央信标和外围补给箱 | 降雪、浓雾 |

降雨削弱火焰与远程、强化水生并浇灭林火；雷暴先预警再落雷，偏向高地并可在水域连锁；浓雾缩短视野和射程；降雪减速并逐渐冻结浅水；酷热增强火焰、削弱治疗并使湿地干涸；沙尘暴降低远程射程与命中。可悬停顶部地图天气条查看数值。熔岩裂隙规则用于后续地图扩展，当前三张测试地图不包含火山地图。

河道保持固定河槽，水面与冰面不整体缩放；抽到降雪后先显示约 12% 的窄岸冰预览，开战后随服务器进度在 20 秒内继续向中线冻结，完全结冰才形成新的地面通路。地图目标可直接悬停查看实际效果、占领条件与奖励：仅己方生物在范围内时，3 秒占领；每军团首次占领单个目标最多获得 2 金币，地图目标每轮共最多 4 金币。补给箱为一次性目标，取走后不再提示可领取奖励。

地图和普通敌军正常可见，取消全屏黑色视野雾；原有索敌、攻击射程与隐蔽发现规则保持。己方隐蔽生物轻微体素淡化，保留阵营圈并显示隐蔽图标，属性框注明 **树林、烟幕或伏击**来源。主动攻击显示**攻击暴露**及服务器同步的 2 秒倒计时；到期且仍满足条件才恢复隐蔽。未发现的隐蔽敌军不下发模型、脚圈、追踪或位置特效，实际发现时仅播放一次轻量反馈。烟幕以局部低矮烟团表现，树林有轻量区域提示，浓雾保留浅色氛围。正常天气索敌视野 **550**、浓雾 **385**、沙尘暴 **440**；侦察生物或己方瞭望塔乘 **1.3**，不重复叠加。

地图点击使用视线遇到的首个有效地表交点，减少穿过前方高地选到后方地面的情况；模型拾取按实际体素部件判断，改善小体型与高低地形上的选中。点击、移动及地形高度使用统一来源。飞行、水生单位按自身规则通行，暂不可达的路线点在执行时投影到可达边缘；浅水结冰开放路线后仍可继续原路线意图。

## 战前战术编排

地形与天气揭晓后，进入 **120 秒**编排。全部存活玩家提前点击「战术完成」也可开战。

| 操作 | 方法 |
| --- | --- |
| 调整生物位置 | 普通左键按住己方生物拖动 |
| 选中单个 | 左键单击 |
| 多选 / 取消其中一只 | Shift + 单击 |
| 框选一组 | **Shift + 按住左键拖框** |
| 全选己方 | Ctrl + A |
| 添加路线点 | 选中生物后右键地面，靠近地图目标时生成占领节点 |
| 保存路线 | 点击「保存路线」；切换小队也会自动保存 |
| 完成编排 | 点击「战术完成」 |

选中的生物有独立地圈，地图绘制箭头、编号和连线，左侧节点卡从上向下执行。框选、选中圈与路线起点跟随生物实际位置，包含拖动和等待摆位确认时的落点；圈线与路径按地表高度采样，并修正 UI 缩放不为 1 时的屏幕投影偏移。支持**移动、占领、伏击、等待、驻守攻击**，以及**立即、开战时间达到、低生命、附近敌人**等条件。节点可调时间或阈值、上下重排或删除，每条路线最多十个节点；面板可收起。

不同小队可保存不同路线，仅所属玩家可见。混选已有不同路线或部分未编排的生物时，显示「多条路线」及各自淡色路线，不把其中一条误当成全组路线；新增节点可为整组选中生物建立新路线，也可明确整组清空。未编排或路线结束的生物继续自动索敌，战术不替代已有天赋。四倍战场的外围也可直接右键布点，缩放、平移和旋转后使用同一地形坐标。淘汰玩家的备战领地不再重新生成军团；战斗中己方团灭后仍可观看其他军团继续交战。

## Steve 指挥技与查看生物

在大厅，或每轮的**招募、准备、未确认的战术编排**中选择一个指挥技：**战鼓、守护结界、集火标记、净化号角、烟幕撤退、工程陷阱、诱饵傀儡、裂隙传送**。圆角选择面板采用紧凑双列布局与弹性反馈，适应 720p 和 900p；独立图标配合悬停说明展示完整作用和关键数值，修复说明中原始颜色标签外露的问题。进入战斗后锁定本场技能，每场两次、间隔 **8 秒**。

战斗默认按 **R** 先进入瞄准，再按 **R** 或左键施放；**Esc / 右键**取消。也可点击技能卡片开始瞄准。落点和集火目标须在 Steve 周围 **200 游戏单位**以内，施法距离圈仅在瞄准时出现；从主菜单或 **Esc → 设置 → 声音与辅助**可分别开关「Steve 施法范围」和「生物攻击范围」，偏好保存在本机。目标、范围、次数与冷却均由服务器校验。

生物血条常态隐藏。**悬停立即显示属性框、生命条、技能名称；开启生物范围显示时绘制攻击范围**。**单击生物打开固定属性框**后显示技能图标、名称与精简实际效果，突出触发条件和数值，包含已购永久技能；技能较多时在技能区内滚动查看。固定属性框可抓住顶部名称栏拖动，窗口随屏幕边界约束；正文滚动和悬停属性框不触发拖动。框内列出攻击、攻速、射程、护甲、移速、视野和当前护盾/状态；战斗属性使用已计天气、地形与指挥技修正的当前数值，移速再计入减速，眩晕或定身时为 0。减速系数随网络快照同步；准备属性包含已购强化，召唤物和分裂体显示自身实际属性。遣散操作保留在己方固定框底部。

默认按 **B** 打开「万物图鉴」：支持中文、英文 ID 和标签搜索，以及友善、中立、敌对、首领分类筛选。列表与详细属性分开呈现，展示物种模型、技能、基础移速、护甲、视野及地面/飞行行动方式。目录沿用 Minecraft Java 1.21.11 的 **89 种独立生物、154 项命名天赋**；不重复计颜色、幼体和骑乘组合。

介绍中的关键字与数值按类型着色，操作使用图标。顶部信息条集中显示阶段、倒计时、地图和天气；图鉴、房间和设置从主菜单、Esc 菜单或设置页进入；底部指挥栏集中指挥技、已购技能、商店及准备操作。主菜单和 Esc 菜单采用统一的图标槽位与文字起点，删除帮助入口后缩短菜单。设置作为独立页面拦截场地输入，技能面板覆盖范围内的点击也不会穿透。指挥官生命条在战斗时常驻右侧，其他阶段自然收至边缘，悬停展开。滚轮缩放、中键拖动镜头，默认 **Q / E** 左右旋转 **90°**，**F** 恢复默认视角；可在按键设置修改。

**Esc** 优先取消瞄准或关闭当前窗口，继续按则打开游戏菜单。菜单可继续游戏、查看图鉴、设置、房间、返回主菜单或退出；从设置打开的图鉴或房间先返回设置，再关闭设置回到原菜单。打开菜单或设置会停止当前移动、寻路和拖选，屏蔽场地操作；**联机对战与倒计时不会暂停**，设置后台的战斗与水晶结算演出继续推进，返回后不重播。返回主菜单会离开房间，房主离开会关闭本机服务器。

## 战斗、演出与声音

战斗由服务器计算独立生物的攻击、攻速、生命、技能和状态。军团全部死亡顺序决定排名和指挥官扣血，超时按剩余总生命排序，同帧团灭可并列；仍存活的指挥官下一轮恢复军团。开战沿用原始军团模型与渲染资源，在准备和编排阶段分帧预热，包含首次受击的身体着色网格与首波召唤物；预热模型保持不激活，避免显示隐藏敌军。不同机器和大阵容的实际帧率仍需实测。

沿用分类挥击、远程弹道、技能符文、状态、受击回弹与死亡体素碎片。战后黑曜石柱和末影水晶逐一攻击败方；本版柱体加宽加高、水晶整体放大，特写按真实模型边界同时容纳发射台与受击者。致命攻击触发 **射线 → 封印 → 爆炸 → 碎裂 → 灵魂升起**，每名目标特写后先拉回全场，再攻击下一人，整轮完成后恢复原视角。结算等待演出完成。

三首原创循环音乐随阶段切换，总音频保持 **50 项（3 首音乐、47 个音效）**。重制十项地图与天气环境音：高台使用稀疏远鸟与空旷石庭回响，沼地使用低缓流水、水滴与低蛙声，霜林使用柔风和偶发冰鸣；雨、雪、酷热和沙尘避免连续高频尖音。循环长 20 秒，雷声为 5 秒低沉滚动；环境切换用 1.65 秒交叉淡化。战斗时环境底音降低 30%，检测到真实语音播放时降至原环境音量的 26%，结束后缓慢恢复。按钮、路线和购买提示保持统一；地图天气轮盘不补播旧节拍，倒计时末段播放提醒。「设置 → 声音与辅助」调节音乐、音效与静音，语音接收有独立静音按钮。音频来源和生成方法见 [原创音频说明](Tools/ArenaAudio-Notes.md)。

## 局域网与内网穿透

**服务器与所有玩家请统一使用 v0.13.0 / 协议 v11**。本版同步隐蔽来源和攻击暴露倒计时，不能与 v0.12.0 / 协议 v10、v0.11.0 / 协议 v9、v0.10.0 / 协议 v8、v0.9.5 / 协议 v7 或更旧客户端混用。公开试玩包见 [v0.13.0 Release](https://github.com/hhhhhhhqcc/BlockArena/releases/tag/v0.13.0)。

点击左下聊天按钮即可输入，也可按 **Enter** 开始输入，**Enter 发送**，Esc 收起输入；中文输入法确认候选不误发，输入时屏蔽场地快捷键。文字消息只在当前房间广播，最多保留 40 条。**默认按住 V 说话**，或点击麦克风按钮切换持续开麦，麦克风默认关闭，断开连接后自动关闭。扬声器按钮可静音其他指挥官，四个小波形标记显示谁正在说话；在大厅也可交流。文字与语音沿用游戏的 TCP 连接及端口，无需单独转发语音端口。Windows 首次使用时需允许桌面应用访问麦克风。

默认 **TCP 7777**，可在开服前修改。朋友须在开始对战前加入：

1. 局域网：房主本机开服，朋友填写同网段房主 IPv4 和端口。
2. 穿透：使用 frp、NATAPP、花生壳等，把 TCP 外网入口映射至房主 `127.0.0.1:7777`；朋友填写映射后的域名 / IP 和外网端口。
3. 虚拟组网：可使用分配的虚拟局域网 IP。地址不要填写网页 URL，仅支持 HTTP 的隧道不能用于本游戏。
4. Windows 防火墙询问时，为实际使用的专用网络允许游戏通信。

断线可在「房间」重连，超过五秒由 AI 操作；房主退出会关闭服务器。玩家包的专用服务器入口为 **联机工具/启动专用服务器.cmd**，首个参数可改端口，日志写在同目录的 `server.log`。源码工程构建后可使用工程启动脚本，或运行：

```powershell
.\Builds\Windows-0.13.0\BlockArena.exe -batchmode -nographics -arena-server -port 7777 -logFile server.log
```

第一位连接者获得房主权限。终局点击「返回大厅」回到大厅，不立即重新开打，房主重新开始后进入新局。

## 工程与验证

- `Assets/Scripts/Core`：纯 C# 权威规则，20Hz 模拟。
- `Assets/Scripts/Networking`：长度前缀 TCP、连接身份绑定、私有招募/战术、10Hz 状态同步。
- `Assets/Scripts/Presentation`：体素模型、阴影灯光、复用特效、地形、动画和平滑镜头。
- `Assets/Scripts/Runtime`：Unity 入口、浮动 UI、输入和 JSON 适配。
- `Tools/CoreChecks`、`Tools/NetworkChecks`、`Tools/CommsChecks`：不依赖 Unity 或第三方 NuGet 的 .NET 8 检查。

本版**本机验收通过**，公开试玩包见 [v0.13.0 Release](https://github.com/hhhhhhhqcc/BlockArena/releases/tag/v0.13.0)。CoreChecks **132/132**、本机 TCP **43/43**、通讯 **10/10**，最终独立 Unity 服务器网络 **28/28**、通讯 **10/10** 通过。最终构建的 **19 套原生专项**通过，其中 **16 份结构化报告合计 2,601 项断言、全部专项共 192 张截图**；包含两种分辨率、完整对局与水晶演出。独立玩家包为 **48,062,222 字节、130 个文件**，中文空格路径独立解压后逐文件 SHA256 一致。开战复用与预热检查通过，但本机固定渲染夹具仍测得 **48.57 / 66.86 毫秒**单帧峰值，不能据此宣称完全无卡顿或各设备帧率达标。复验入口为 `Tools/Verify-VisibilityUpdate.ps1 -ShowWindows`，最终报告为 `.checks/0.13.0/final-verification.json`，截图在 `Captures/0.13.0`；分项、性能范围及最终哈希见 [验证记录](验证记录.md)。正式安装已校验 369 文件基线、逐文件备份与哈希校验，保留旧版文件。真实麦克风、外部扬声器听感、第二台实体设备、具体内网穿透链路及大阵容长期帧率仍需实测。

原型暂未加入账号、存档或匹配。军团没有玩法数量上限，大阵容仍受主机 CPU、绘制及带宽限制；本机 TCP 检查不等同于第二台实体设备或具体内网穿透链路验收。
