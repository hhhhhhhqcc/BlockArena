# 方块斗兽场 · Unity 原型 0.9.5

四位指挥官招募方块生物、自由布阵，再让军团自动混战。支持本机对战三位电脑、局域网联机和自行配置 TCP 内网穿透。

[下载 v0.9.5 Windows 试玩包](https://github.com/hhhhhhhqcc/BlockArena/releases/download/v0.9.5/BlockArena-v0.9.5-Windows-x64.zip) · [Releases](https://github.com/hhhhhhhqcc/BlockArena/releases/tag/v0.9.5) · [生物图鉴](生物图鉴.md) · [Windows 试玩说明](Windows-试玩说明.md) · [验证记录](验证记录.md)

当前版本为 **v0.9.5 / 协议 v7**。单人试玩直接过渡到对局，不再闪现联机大厅；创建和加入房间仍先填写配置。设置升级为独立页面，配有动态水晶工坊背景，集中声音、范围辅助、显示模式与分辨率，并可进入图鉴、帮助和当前房间。移除右上常驻工具入口，主菜单与 **Esc** 菜单统一图标和文字对齐。Steve 的 **WASD / 方向键按当前镜头方向移动**，生物单击固定属性框后可查看精简技能效果。沿用 **45 秒共享准备**、三张地图、七种天气与 **120 秒战术编排**；音频仍为 **40 项（3 首音乐、37 个音效）**。构建及验收状态见 [验证记录](验证记录.md)。

使用 Unity **2022.3.62f3c1**、Built-in 渲染管线。工程根目录可直接由 Unity 打开，Windows 客户端输出目录为 `Builds/Windows-0.9.5`。构建文件与 Unity 缓存不提交到 Git，网页原型不属于本仓库。仍采用 v0.8 的构筑与经济，不包含遗物或单体装备系统。

## 开始试玩

从 Releases 下载 **BlockArena-v0.9.5-Windows-x64.zip**，完整解压后双击最外层的 **开始游戏.cmd**。试玩包只包含中文入口、简短说明、`游戏文件` 和 `联机工具`，无需打开工程目录，也无需安装 Unity、.NET SDK 或 Node。向朋友分享时保留整个解压目录，不要只拷贝 exe；GitHub 自动生成的 Source code 是源码工程。

- **单人试玩**：本机开服并添加三位电脑，过渡期间保留主菜单背景，直接进入对局；Esc 可取消进入。
- **创建房间**：先填写昵称与 TCP 端口，确认后开服进入大厅；房主开始时，空位可由电脑补齐。
- **加入房间**：先填写昵称、房主 IP / 穿透域名与 TCP 端口，确认后连接；连接中可取消并保留配置，失败后可修改重试。昵称、地址和端口保存在本机，最多四位玩家。
- **对局结束**：联机房主点击「返回大厅」返回原房间大厅，重新确认后开始新局。

主界面、创建房间、加入房间分别展示实时体素场景，大厅沿用对应背景。大厅四个席位集中展示玩家，可复制连接地址、选择指挥技；房主还能设置战场和开始对战。主菜单可打开图鉴、设置和玩法帮助，帮助分为基本操作、招募与金币、战术与指挥、联机四页。独立设置页使用第四套实时体素场景：铜制齿轮围绕悬浮水晶缓慢转动，红石回路与微光粒子构成工坊背景。

开发者可在 Unity Hub 添加源码工程根目录，使用上述 Unity 版本打开 `Assets/Scenes/Arena.unity` 后点击 Play；菜单 **方块斗兽场 → 打开试玩场景** 也可打开。菜单 **方块斗兽场 → 构建 Windows 试玩版** 输出至 `Builds/Windows-0.9.5`，构建后可使用工程根目录的启动脚本。本机安装路径匹配时，也可运行 **打开Unity工程.cmd**。运行 `Tools/Package-Release.ps1` 可将构建整理成上述玩家包，输出至 `Releases/v0.9.5`，同时生成 SHA256 校验文件；已存在的输出不会被覆盖。

设置分为「声音与辅助」和「显示设置」。显示页可选择**窗口 / 无边框全屏**及分辨率，点击「应用设置」后生效；以系统实际接受的模式和尺寸保存，下次启动使用。显示偏好保存在原生客户端本机，不随房间同步，服务器不保存；自动测试模式不读取或改写这些偏好。设置页也提供图鉴、玩法手册及当前房间入口，按 Esc 先关闭子页，再返回设置或游戏菜单。

## 招募、布阵与金币

每位指挥官 **20 点生命**，开局 **12 金币、两只基础生物**。开局及每轮战后，从三个不同候选中花金币招募一只，或跳过保留金币。招募卡片展示技能、精简效果和关键数值，可花 **2 金币「换一批」**更换候选，每轮仍最多买一只。超时由服务器购买可负担的生物，全部买不起则跳过。

每轮从招募出现起共用 **45 秒**准备时间；所有人完成招募后切换到布阵阶段，**保留剩余时间，不重新计时**。各人完成选择后即可布阵、购买技能或点击准备，不必等别人招募完。全部存活玩家均完成招募并准备好时，可提前开始地图揭晓。

招募页面可以**收起**，回场地查看生物、调整摆位或遣散，再点击「招募援军」恢复。收起不会购买或跳过，也不会暂停服务器倒计时。原「军团」窗口已移除：**单击生物打开固定属性框**，招募或准备时在己方生物属性框中遣散，返还实际购买价的一半、向下取整；免费初始生物返还 0，至少保留一只。待招募时可先遣散筹钱，再恢复招募页完成选择。

准备时只显示自己的独立领地。生物在地上活动，可拖到有效区域内任意位置，没有格子。拖动保留鼠标抓取偏移，服务器确认前保留落点以减轻延迟回弹。WASD / 方向键按当前镜头的屏幕方向移动 Steve，四个席位和镜头转动时保持一致；或点击地面让 Steve 自动绕开地图障碍前往。

按 **M** 或点击商店购买永久技能，每批最多四项未掌握技能，准备期间不会定时自动换货；可花 **2 金币**主动刷新。共 13 项物种/类别技能，购买一次便作用于匹配的现有及未来生物，跨回合保留。技能详情列出全部适用物种、当前匹配数量；悬停时高亮场上匹配的己方生物。已购技能收藏保留。

有效击杀敌方原始军团生物，**每只 1 金币即时到账，每人每轮最多 5 金币**。战后补发 **基础 6 + 名次奖励 4/3/2/2**，常规整轮收入为 **6 + min(5，击杀数) + 名次奖励**，即 **8～15 金币**。召唤物和分裂体不给普通击杀金，毒、灼烧及己方召唤物击杀归主人。领先者按指挥官生命、上轮名次、军团战力选定并锁定，带琥珀皇冠；其他玩家每击杀其三只原始生物额外得一金币，每轮最多三金币。遣散、悬赏与地图目标奖励另计。

**旧中央守卫／随机金币事件及招募后的事件预告已移除。** 圣坛、矿脉、瞭望塔、信标和补给箱随对应地图自然生成，作为固定争夺目标；地图目标收入受每轮上限约束。

## 地图与天气

本轮流程为：**45 秒共享准备（招募、独立领地布阵、商店）→ 回到正常竞技场 → 抽取地图 → 地形完整升起 → 抽取并揭晓天气 → 120 秒战术编排 → 自动战斗 → 水晶结算**。揭晓总计约 **11 秒**，地图生成配合音效与轻微振动。房主可在大厅「战场设置」指定地图或天气，默认按地图池随机。

| 地图 | 地形与固定目标 | 默认天气池 |
| --- | --- | --- |
| 四庭高台 | 中央高地、四座窄桥、两侧废墟；中央圣坛 | 晴朗、雷暴 |
| 腐沼矿场 | 湿地、密林、废墟；两处矿脉与瞭望塔 | 降雨、浓雾、酷热 |
| 霜林遗迹 | 密林、浅水、高地；中央信标与补给箱 | 降雪、浓雾 |

降雨削弱火焰与远程、强化水生并浇灭林火；雷暴先预警再落雷，偏向高地并可在水域连锁；浓雾缩短视野和射程；降雪减速并逐渐冻结浅水；酷热增强火焰、削弱治疗并使湿地干涸；沙尘暴降低远程射程与命中。可悬停顶部地图天气条查看数值。熔岩裂隙规则用于后续地图扩展，当前三张测试地图不包含火山地图。

地图点击使用视线遇到的首个有效地表交点，减少穿过前方高地选到后方地面的情况；模型拾取按实际体素部件判断，改善小体型与高低地形上的选中。点击、移动及地形高度使用统一来源。飞行、水生单位按自身规则通行，暂不可达的路线点在执行时投影到可达边缘；浅水结冰开放路线后仍可继续原路线意图。

## 战前战术编排

地形与天气揭晓后，进入 **120 秒**编排。全部存活玩家提前点击「战术完成」也可开战。

| 操作 | 方法 |
| --- | --- |
| 调整生物位置 | 普通左键按住己方生物拖动 |
| 选中单个 | 左键单击 |
| 多选 / 取消其中一只 | Shift + 单击 |
| 框选一组 | **Shift + 按住左键拖框** |
| 全选己方 | Ctrl + A |
| 添加路线点 | 选中生物后右键地面，靠近地图目标时生成占领节点 |
| 保存路线 | 点击「保存路线」；切换小队也会自动保存 |
| 完成编排 | 点击「战术完成」 |

选中的生物有独立地圈，地图绘制箭头、编号和连线，左侧节点卡从上向下执行。框选、选中圈与路线起点跟随生物实际位置，包含拖动和等待摆位确认时的落点；圈线与路径按地表高度采样，并修正 UI 缩放不为 1 时的屏幕投影偏移。支持**移动、占领、伏击、等待、驻守攻击**，以及**立即、开战时间达到、低生命、附近敌人**等条件。节点可调时间或阈值、上下重排或删除，每条路线最多十个节点；面板可收起。

不同小队可保存不同路线，仅所属玩家可见。混选已有不同路线或部分未编排的生物时，显示「多条路线」及各自淡色路线，不把其中一条误当成全组路线；新增节点可为整组选中生物建立新路线，也可明确整组清空。未编排或路线结束的生物继续自动索敌，战术不替代已有天赋。淘汰玩家的备战领地不再重新生成军团；战斗中己方团灭后仍可观看其他军团继续交战。

## Steve 指挥技与查看生物

在大厅，或每轮的**招募、准备、未确认的战术编排**中选择一个指挥技：**战鼓、守护结界、集火标记、净化号角、烟幕撤退、工程陷阱、诱饵傀儡、裂隙传送**。圆角选择面板采用紧凑双列布局与弹性反馈，适应 720p 和 900p；独立图标配合悬停说明展示完整作用和关键数值，修复说明中原始颜色标签外露的问题。进入战斗后锁定本场技能，每场两次、间隔 **8 秒**。

战斗按 **Q** 先进入瞄准，再按 **Q** 或左键施放；**Esc / 右键**取消。也可点击技能卡片开始瞄准。落点和集火目标须在 Steve 周围 **200 游戏单位**以内，施法距离圈仅在瞄准时出现；从主菜单或 **Esc → 设置 → 声音与辅助**可分别开关「Steve 施法范围」和「生物攻击范围」，偏好保存在本机。目标、范围、次数与冷却均由服务器校验。

生物血条常态隐藏。**悬停立即显示属性框、生命条、技能名称；开启生物范围显示时绘制攻击范围**。**单击生物打开固定属性框**后显示技能图标、名称与精简实际效果，突出触发条件和数值，包含已购永久技能；技能较多时在技能区内滚动查看。框内保留生命、实际战斗属性和状态，遣散操作始终在己方生物固定框的底部。准备属性包含已购强化，召唤物和分裂体显示自身实际属性。

按 **B** 打开「万物图鉴」：支持中文、英文 ID 和标签搜索，以及友善、中立、敌对、首领分类筛选。列表与详细属性分开呈现，展示物种模型、技能和关键数值。目录沿用 Minecraft Java 1.21.11 的 **89 种独立生物、154 项命名天赋**；不重复计颜色、幼体和骑乘组合。

介绍中的关键字与数值按类型着色，操作使用图标。顶部信息条集中显示阶段、倒计时、地图和天气；右上常驻工具入口已移除，图鉴、帮助、房间和设置从主菜单、Esc 菜单或设置页进入；底部指挥栏集中指挥技、已购技能、商店及准备操作。主菜单和 Esc 菜单采用统一的图标槽位与文字起点。设置作为独立页面拦截场地输入，技能面板覆盖范围内的点击也不会穿透。指挥官生命条在战斗时常驻右侧，其他阶段自然收至边缘，悬停展开。滚轮缩放、中键拖动镜头，**F** 恢复默认视角。

**Esc** 优先取消瞄准或关闭当前窗口，继续按则打开游戏菜单。菜单可继续游戏、查看图鉴、设置、帮助、房间、返回主菜单或退出；从设置打开的图鉴、帮助或房间先返回设置，再关闭设置回到原菜单。打开菜单或设置会停止当前移动、寻路和拖选，屏蔽场地操作；**联机对战与倒计时不会暂停**，设置后台的战斗与水晶结算演出继续推进，返回后不重播。返回主菜单会离开房间，房主离开会关闭本机服务器。

## 战斗、演出与声音

战斗由服务器计算独立生物的攻击、攻速、生命、技能和状态。军团全部死亡顺序决定排名和指挥官扣血，超时按剩余总生命排序，同帧团灭可并列；仍存活的指挥官下一轮恢复军团。

沿用分类挥击、远程弹道、技能符文、状态、受击回弹与死亡体素碎片。战后黑曜石柱和末影水晶逐一攻击败方；致命攻击触发 **射线 → 封印 → 爆炸 → 碎裂 → 灵魂升起**，每名目标特写后先拉回全场，再攻击下一人，整轮完成后恢复原视角。结算等待演出完成。

三首原创循环音乐随阶段切换，音频资源仍为 **40 项**。按钮统一使用短木石点击声，键盘开关与鼠标点击保持相同音量；轻量悬停声也更新为原创合成音。路线编辑不再把按钮音与放置音叠播，地图上的选中、拖放和路线布点保留对应反馈。购买和换技先播放操作点击，服务器确认成功后才播放对应确认音；拒绝、重复快照和重连不补播确认。地图与天气轮盘由快到慢，画面与滴答共用节拍，延迟不补播旧节拍。「设置 → 声音与辅助」分别调音乐、音效或静音。倒计时末段播放提醒，不为重连补播错过的秒数。音频来源和生成方法见 [原创音频说明](Tools/ArenaAudio-Notes.md)。

## 局域网与内网穿透

**服务器与所有玩家请统一使用 v0.9.5 / 协议 v7**。本版未升级协议；v0.9.1 / 协议 v6 及更旧客户端不能混用。朋友可下载同一份 Windows 试玩包。

默认 **TCP 7777**，可在开服前修改。朋友须在开始对战前加入：

1. 局域网：房主本机开服，朋友填写同网段房主 IPv4 和端口。
2. 穿透：使用 frp、NATAPP、花生壳等，把 TCP 外网入口映射至房主 `127.0.0.1:7777`；朋友填写映射后的域名 / IP 和外网端口。
3. 虚拟组网：可使用分配的虚拟局域网 IP。地址不要填写网页 URL，仅支持 HTTP 的隧道不能用于本游戏。
4. Windows 防火墙询问时，为实际使用的专用网络允许游戏通信。

断线可在「房间」重连，超过五秒由 AI 操作；房主退出会关闭服务器。玩家包的专用服务器入口为 **联机工具/启动专用服务器.cmd**，首个参数可改端口，日志写在同目录的 `server.log`。源码工程构建后可使用工程启动脚本，或运行：

```powershell
.\Builds\Windows-0.9.5\BlockArena.exe -batchmode -nographics -arena-server -port 7777 -logFile server.log
```

第一位连接者获得房主权限。终局点击「返回大厅」回到大厅，不立即重新开打，房主重新开始后进入新局。

## 工程与验证

- `Assets/Scripts/Core`：纯 C# 权威规则，20Hz 模拟。
- `Assets/Scripts/Networking`：长度前缀 TCP、连接身份绑定、私有招募/战术、10Hz 状态同步。
- `Assets/Scripts/Presentation`：体素模型、阴影灯光、复用特效、地形、动画和平滑镜头。
- `Assets/Scripts/Runtime`：Unity 入口、浮动 UI、输入和 JSON 适配。
- `Tools/CoreChecks`、`Tools/NetworkChecks`：不依赖 Unity 或第三方 NuGet 的 .NET 8 检查。

本版复验入口为 `Tools/Verify-SettingsUpdate.ps1 -ShowWindows`，日志为 `.checks/*-0.9.5.log`，截图归档到 `Captures/0.9.5`。[验证记录](验证记录.md) 分开记录当前与历史结果，旧版通过项不代表本次已通过。
